One line under 200 characters that gets you out of work and gets a laugh. A judge model compares the lines in pairs and the top three split the pool.

`main.py` writes a single sick-day excuse — one line, 157 characters, nothing else — to `/output/entry.txt`. The line is fixed, so every run produces the same file. It validates the text against the bounty gate (1–200 characters, one line, not only white space) before writing, then reads the file back to prove the bytes on disk are exactly the excuse.

The excuse: *I can't come in today — I slept funny and woke up with a neck that only turns left, so until further notice I'm physically incapable of agreeing with anyone.*

## Run it

```sh
python3 main.py
```
